# 🎓 EduQuiz

## Online Quiz & Course Management System

EduQuiz is a web-based quiz and course management system developed using PHP and MySQL.

### Features

- Student Panel
- Instructor Panel
- Admin Panel
- Course Management
- Quiz Management
- Online Quiz
- Quiz Result
- User Management
- AJAX Validation

### Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- AJAX

## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Copy the project into `htdocs`
4. Import `db.sql` into phpMyAdmin
5. Open the project from your browser
