# 🎓 EduQuiz

### Online Quiz & Course Management System

EduQuiz is a web-based application designed to manage courses, quizzes, students, instructors, and quiz results.

## ✨ Features

- 👨‍🎓 Student Panel
- 👨‍🏫 Instructor Panel
- 🛡️ Admin Panel
- 📚 Course Management
- 📝 Quiz Management
- 🎯 Online Quiz
- 📊 Quiz Results
- 👥 User Management
- ⚡ AJAX Validation

## 🛠️ Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- AJAX

## ⚙️ How to Run

1. Install **XAMPP**
2. Start **Apache** and **MySQL**
3. Copy the project to the `htdocs` folder
4. Open **phpMyAdmin**
5. Create a database and import `db.sql`
6. Open the project in your browser

```text
http://localhost/EduQuiz/
