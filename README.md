# EduQuiz-Online-Quiz-Management-System

This is a PHP and MySQL based web application for managing online courses and quizzes. It provides separate panels for Students, Instructors, and Admins.

## Features

- Student, Instructor, and Admin panels.
- Course and quiz management.
- Students can take quizzes and view results.
- Instructors can create quizzes and manage courses.
- Admin can manage users and courses.
- AJAX based validation.
- MySQL database integration.

## Setup Instructions

- Clone the repository to your local machine.
- Install and open XAMPP.
- Start Apache and MySQL.
- Copy the project folder into the `htdocs` folder.
- Create a database in phpMyAdmin.
- Import the `db.sql` file into the database.
- Configure the database connection if required.
- Open the project in your browser.

## Usage

Once configured, students can enroll in courses, take quizzes, and view their results. Instructors can manage courses and quizzes, while admins can manage users and the overall system.
